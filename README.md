# ITD EXTENDED v0.3.0

Браузерное расширение (Chrome Manifest V3) для социальной платформы ИТД: счётчик непрочитанных, аналитика профиля, полные числа, кринж-сканер постов и собственный баннер.

## Установка

1. Открыть `chrome://extensions` и включить режим разработчика.
2. «Загрузить распакованное расширение» → выбрать эту папку (в корне лежит `manifest.json`).
3. Открыть `итд.com`.

## Структура

- `manifest.json` — манифест расширения.
- `src/background.js` — service worker: перехват и хранение токена сессии.
- `src/content.js` — внедрение интерфейса и запросы к API сайта.
- `src/panel.js` — панель расширения.
- `src/changelog.js` — инжект списка изменений.
- `assets/` — иконки.
- `CHANGELOG.md`, `IDEAS.md`, `V1-SCOPE.md` — история версий и планы.

Токен авторизации читается из сессии сайта и используется только для запросов к `итд.com`; наружу не передаётся.
